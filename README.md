# 쇼츠픽 (ShortsPick) — 설치 파일 배포소

AI 유튜브 쇼츠 제작 데스크톱 앱 **쇼츠픽**의 설치 파일을 배포하는 저장소입니다.

> 이 저장소에는 **소스코드가 없습니다.** 설치 파일(Release)만 올라갑니다.

## 다운로드

### 👉 [최신 버전 받기](../../releases/latest)

| 운영체제 | 받을 파일 |
|---|---|
| Windows 10 / 11 (64비트) | `ShortsPick-x.x.x-Windows.exe` |
| macOS (Apple Silicon · M1 이상) | `ShortsPick-x.x.x-Mac-arm64.dmg` |

## 설치 안내

### 🪟 Windows

내려받은 `.exe` 를 실행하세요.

SmartScreen 경고가 뜨면 **"추가 정보" → "실행"** 으로 진행합니다.
(코드서명 인증서 도입 전까지 표시되는 일반 안내입니다.)

### 🍎 macOS

Apple 개발자 인증서로 서명되지 않아 처음 실행 시 **"확인되지 않은 개발자"** 또는
**"손상되었기 때문에 열 수 없습니다"** 경고가 나올 수 있습니다. 아래 절차로 정상 실행됩니다.

1. `.dmg` 를 내려받아 더블클릭 → 앱을 **응용 프로그램(Applications)** 폴더로 드래그
2. **응용 프로그램**에서 `쇼츠픽` 실행 → 경고가 뜨면 **"취소"** (휴지통으로 보내지 마세요)
3. **🍎 → 시스템 설정 → 개인정보 보호 및 보안** 으로 이동
4. 아래로 스크롤 → **"그래도 열기"** 클릭 → 다시 **"열기"**. 완료!

> 최초 1회만 거치면 됩니다. Apple 공증을 받지 않은 모든 앱에 나오는 일반 안내입니다.

## 자동 업데이트

앱이 새 버전을 자동으로 확인해 알려줍니다.

- **Windows** — 앱 안에서 바로 내려받아 설치됩니다.
- **macOS** — 알림의 버튼을 누르면 이 저장소의 최신 릴리스 페이지가 열립니다.
